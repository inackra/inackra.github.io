# Проверка исходников — 21 ноября 2026

База проверки: публичный репозиторий `inackra/inackra.github.io`, коммит `70c0ea7`, и подготовленные после него изменения.

Проверены текущие текстовые исходники, 141 уникальная версия текстовых файлов из 11 доступных коммитов Git и новая локальная production-сборка. Выполнен поиск сигнатур распространённых API-токенов, приватных ключей, JWT, учётных данных в URL и присваиваний секретов. Дополнительно просмотрены загрузка медиа, форма заявок, Apps Script и настройки сборки.

**Результат: пароли, приватные ключи, API-токены и R2 Access/Secret Key в проверенных материалах не обнаружены.** Среди отслеживаемых файлов нет `.env` или файлов приватных ключей. Это ограниченная проверка исходников, а не гарантия отсутствия любых уязвимостей.

## Что видно посетителю

- `media.inackra.work` и `key` в каталоге — публичный адрес и имена файлов. Это не ключи доступа к аккаунту Cloudflare. Для публичного показа работ браузеру необходимы адреса файлов.
- Адрес приёма заявок Google Apps Script является публичной точкой отправки формы. В проверенном коде есть `doPost`, но нет HTTP-обработчика чтения заявок. Ответ содержит идентификатор запроса и результат отправки, без строк таблицы.
- Идентификатор таблицы читается на сервере из Script Properties. В код сайта не передаются OAuth-учётные данные. Код защищает записываемые поля от формул, проверяет длины и email, использует ловушку для ботов и ограничение частоты по email. Это не полная защита от спама.
- В сборке используются только публичные параметры сайта: адрес медиа и адрес приёма формы. Секретные API-ключи нельзя помещать в переменные `VITE_*`: такие значения могут попасть в клиентский код.

## Ограничения проверки

Текущие настройки общего доступа Google Sheets, активные токены и права в аккаунтах Cloudflare/GitHub/Google в рамках этой проверки не инспектировались. Содержимое изображений, видео и PDF не проходило отдельную проверку на персональные данные. История, не доступная в клоне репозитория, также не проверялась.

Убраны прямые ссылки на оригиналы и открытие файлов из просмотрщика в новой вкладке. Добавлены ограничения контекстного меню, перетаскивания и скачивания через стандартные видеоконтролы. Они сокращают число очевидных способов сохранения, но не запрещают копирование публично показанного контента через инструменты браузера или снимок экрана.

Добавлен `.gitignore` для локальных конфигураций, приватных ключей, сборки и временных файлов. Он помогает при работе через Git, но не заменяет проверку файлов, которые вручную загружаются через интерфейс GitHub.
